A · Cloudflare Worker — ตัวกลางดึงข้อมูลเครื่องบิน (ทำครั้งเดียว ~5 นาที)

API เครื่องบินไม่ยอมให้เว็บเรียกตรง Worker คือโปรแกรมเล็กๆ บนเซิร์ฟเวอร์ฟรีของ Cloudflare ที่ไปดึงให้แทน · แพ็กเกจ Free ใช้ได้ 100,000 ครั้ง/วัน ถ้าเกินแค่หยุดทำงานถึงวันรุ่งขึ้น ไม่มีการเก็บเงิน

  1. เปิด dash.cloudflare.com/sign-up/workers สมัครด้วยอีเมล (ฟรี ไม่ต้องใส่บัตร)
  2. เมนูซ้าย Workers & Pages → Create → Create Worker (เลือกแบบ Hello World) → ตั้งชื่อ เช่น ksd-proxy → Deploy
  3. กด Edit code → ลบโค้ดเดิมทั้งหมด → วางโค้ดด้านล่าง → Deploy
  4. คัดลอกลิงก์ของ Worker (หน้าตาแบบ https://ksd-proxy.ชื่อคุณ.workers.dev) มาวางในช่องด้านล่างแล้วกด "บันทึก + ทดสอบ"
ไฟล์: lab/remote/worker.js

B · Tailscale — เข้าคอมที่ทำงานจากที่ไหนก็ได้ (VPN ส่วนตัว ฟรี)

iPhone จะคุยกับคอมที่ทำงานผ่านอุโมงค์เข้ารหัส เหมือนนั่งอยู่ในบริษัท — ไม่เปิดเว็บสู่สาธารณะ คนอื่นเข้าไม่ได้ · แพ็กเกจ Personal ฟรี (สูงสุด 3 ผู้ใช้ 100 เครื่อง)

⚠ ติดตั้งโปรแกรม VPN บนคอมของบริษัท ควรแจ้ง/ขออนุญาตฝ่าย IT ก่อน
  1. คอมที่ทำงาน: ดาวน์โหลด tailscale.com/download/windows → ติดตั้ง → Log in (ใช้บัญชี Google ก็ได้) → เลือกแพ็กเกจ Personal (Free)
  2. iPhone: ลงแอป Tailscale จาก App Store → Log in บัญชีเดียวกัน → เปิดสวิตช์ Connected
  3. เข้า login.tailscale.com/admin/dns → เปิด MagicDNS และ HTTPS Certificates (ฟรี — ทำให้กล้อง/ไมค์ใช้ได้ด้วย)
  4. บนคอมที่ทำงาน เปิด Command Prompt (Run as administrator) แล้วพิมพ์:
    tailscale serve --bg http://localhost:80
    จะได้ลิงก์ https://ชื่อคอม.xxxx.ts.net/
  5. บน iPhone (เปิด Tailscale อยู่) เข้า https://ชื่อคอม.xxxx.ts.net/ksd/lab/ — ใช้ได้ทุกระบบ รวมถึง Twin, NET//RADAR, ห้องพยาบาล, ลงเวลา

ต้องการ: คอมที่ทำงานเปิดอยู่ (ตั้ง Windows ไม่ให้ Sleep) + XAMPP Apache ทำงาน + Tailscale ทำงาน · ลิงก์ .ts.net เปิดได้เฉพาะเครื่องที่ล็อกอิน Tailscale บัญชีเดียวกันเท่านั้น · ยกเลิกการแชร์: tailscale serve reset
